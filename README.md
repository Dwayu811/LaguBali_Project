## Topik Aplikasi
Topik aplikasi berada pada cakupan aplikasi Katalog dimana saya membuat katalog lagu anak-anak Bali (Gending Rare) selain itu, aplikasi ini dibangun untuk memenuhi Ujian Akhir Semester (UAS) mata kuliah Pemrograman Seluler.
Aplikasi ini mendemonstrasikan penguasaan materi, meliputi:
1. **Modul 2 & 3**: Desain UI yang rapi dan Responsif (Wajib memiliki tampilan yang menyesuaikan saat layar HP di-landscape).
2. **Modul 4 & 5**: Terdapat perpindahan halaman (Intent) dan validasi If-Else pada kolom input.
3. **Modul 6**: Menggunakan struktur data Array dan mengimplementasikan fitur Pencarian Data (Linear Search).
4. **Modul 7**: Mengimplementasikan fitur Pengurutan Data dari A-Z dan Z-A menggunakan algoritma Bubble Sort.
5. **Modul 9**: Memiliki penanganan Error (try-catch) dan merekam aktivitas aplikasi di latar belakang menggunakan Logcat (Gunakan NIM kalian sebagai Tag Logcat).
